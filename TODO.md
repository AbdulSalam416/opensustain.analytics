`streamlit-app-tab.py`, then putting it in production.

are all **unblocked on data** — every payload the missing work needs is
already generated by `scripts/build_analytics_payloads.py`. E is

## Country filters — needs a decision before starting

**Projects have no country.** There is no country column in
`data/projects.csv` and no country field in `project-rankings.json` or
`projects-over-time.json`. Only organisations carry `location_country`.

- [ ] Organisation views — a country filter works today from existing data
- [ ] **Decide:** project views need a country attached per project in
      `scripts/build_analytics_payloads.py`. The join already exists there
      (organisations → projects on a normalised git URL), but that file is
      regenerated by the `update_data` workflow, so changing it is a call
      to make deliberately
- [ ] Use `organizations-overview.countries` (43, ISO-coded), **not**
      `filters.countries` — the latter is built from raw `location_country`
      with no cleaning and contains "Berlin", a city

## Production blockers

Independent of feature parity. None of these are about the charts.

- [ ] **There is no deploy path for the Next.js app.** `Dockerfile` is
      `python:3.13-slim` running `streamlit run`, and `deploy-package.yaml`
      ships only that image. `.gitignore` already lists `web/out/`, so a
      static export looks like the original intent — `next.config.ts` has no
      `output` mode set
- [ ] **No CI touches the web app.** Four workflows, none run npm.
      Add a typecheck + build gate; it would have caught the type error the
      old sunburst shipped with
- [ ] **No error boundaries.** `app/` has no `error.tsx` or
      `global-error.tsx`, so any render-time throw replaces the page with
      Next's exception screen
- [ ] **No tests.** No test tooling in the repo at all
- [ ] **Every route shares one title.** Metadata is defined only in
      `layout.tsx`; all four routes present as "OpenSustain Analytics"
- [ ] **Next 15.5.2 advisory.** pnpm flags CVE-2025-66478 on the pinned
      version
- [ ] **`web/tsconfig.tsbuildinfo` is tracked** and churns on every
      typecheck; it belongs in `.gitignore`
- [ ] Update `README.md` — it does not mention the web app at all
